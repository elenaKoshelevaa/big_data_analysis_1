# РАЗРАБОТКА ПРОГРАММНОГО МОДУЛЯ ТЕХНИЧЕСКОГО ЗРЕНИЯ ДЛЯ ПРОМЫШЛЕННОГО МОБИЛЬНОГО РОБОТИЗИРОВАННОГО КОМПЛЕКСА

## Назначение программного модуля
Разрабатываемый модуль предназначен для автоматизированного **анализа видеопотока**,
получаемого от камеры мобильной роботизированной платформы, выполняющей
инспекционный обход промышленной территории. Основная обработка изображений
производится локально на бортовом вычислительном устройстве, что позволяет снизить
зависимость от внешнего канала связи и уменьшить задержку реакции на события.
Модуль должен принимать видеопоток, извлекать кадры, выполнять предварительную
обработку, запускать модели компьютерного зрения, отслеживать обнаруженные объекты,
анализировать контролируемые области изображения, формировать события, сохранять
подтверждающие изображения, вести журнал и предоставлять результаты внешнему
программному интерфейсу.

## Установка и запуск
1. Клонировать репозиторий.
2. Создать виртуальное окружение: 
`python -m venv .venv`
Linux/macOS
`source .venv/bin/activate`
Windows PowerShell
`.venv\Scripts\Activate.ps1`
`python -m pip install --upgrade pip`
3. Установить зависимости: `pip install -r requirements.txt`

*Остальные инструкции будут добавлены по мере разработки*
